# Tell a Whole Story in 32 Characters

An entry for the make.fun bounty "Tell a Whole Story in 32 Characters". The program writes a single Wi-Fi network name of 27 characters. A stranger scrolling the network list reads a situation, a character, and something that happened: Dave took the kids, and he took the router too. The network name is the only place the other side of the story gets told, and the petty final detail is what makes the whole thing land.

## Entry

> DaveTookTheKidsAndTheRouter

## How it works

Run with Node 22.18+: `node main.ts`, writes the entry to /output/entry.txt.
